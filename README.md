# Object Populator-inator

## What?

I thought it would be self-explanatory but let me put it a little simpler: I do not enjoy placing environment objects around the scene en masse. It's annoying, and inconvenient.
What if I could hypothetically, say, press a button and have them placed from a specific origin point, with density and radius options?
...
...
*That's what this is for.*
I just hate doing it myself, so I'll make something that does it for me.
